Architecture · n8n pipeline (draft)

One workflow runs everything, end to end

1 · Trigger

n8n Form: one job offer and three CV PDFs

2 · Read

PDF text extraction; vision model if scanned or multi-column

3 · Anonymize

Regex + NER strip name, e-mail, phone, address, photo

4 · CV Agent ×3

One structured JSON profile per CV, run in parallel

5 · Job Analysis Agent

Weighted must-have and nice-to-have requirements

6 · Index

Chunk CVs, embed, store in Qdrant with candidate_id

7 · Matching Agent

Per requirement: retrieve evidence, decide status and score

8 · Audit Agent

Checks each claim; sends back once or flags it, then report

SmartRecruit · Week 1 check-in · 6 · Dark cards are LLM agents; light cards are deterministic n8n nodes

The orchestration is the n8n workflow itself: deterministic, logged at every node, and re-runnable. LLMs are only used where judgement is needed.
